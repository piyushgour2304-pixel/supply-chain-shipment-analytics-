# Supply Chain & Shipment Analytics Dashboard

## Project Overview
This project focuses on analyzing supply chain and shipment data using Microsoft Power BI. The dashboard provides insights into shipment performance, transportation costs, sales value, profit margins, delivery status, and transit time to support data-driven business decisions.

## Objectives
- Analyze shipment and delivery performance.
- Monitor sales value, shipment volume, and transportation costs.
- Track profit margins and average shipment value.
- Identify delivery delays and shipment exceptions.
- Build an interactive dashboard for logistics performance monitoring.

## Tools & Technologies
- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – KPI calculations and measures
- **Data Modeling** – Organizing data for analysis
- **Microsoft Excel / CSV** – Data preparation, where applicable

## Key Performance Indicators (KPIs)
- Total Sales
- Total Shipments
- Total Boxes
- Average Shipment Value
- Total Cost
- Profit Margin

## Dashboard Features
- Interactive KPI cards
- Shipment performance analysis
- Delivery status monitoring
- Transit time analysis
- Cost and profit margin insights
- Shipment exception tracking
- Interactive filters and slicers

## Dataset Information
The project uses shipment data containing fields such as Shipment ID, Delivery Date, Exception, Cost, Transit Time, and other shipment-related attributes.

## Project Workflow
1. Import the shipment dataset.
2. Clean and transform data using Power Query.
3. Build relationships and organize the data model.
4. Create measures and KPIs using DAX.
5. Design interactive Power BI visualizations.
6. Analyze results to identify operational trends and insights.

## Business Benefits
- Helps monitor logistics and shipment performance.
- Supports transportation cost analysis.
- Highlights delivery issues and exceptions.
- Improves visibility into operational performance.
- Supports data-driven supply chain decisions.

1. Download the `.pbix` file from this repository.
